# BeatVideoCutter

Автоматический видеомонтаж под музыку.
Программа берёт набор видеофайлов и один аудиотрек, анализирует ритм
музыки и собирает итоговый клип, в котором смена кадров приходится на
сильные доли (биты) композиции.

Интерфейс: десктопное GUI-приложение на Python/tkinter, тёмная
минималистичная тема. Консольного режима нет.

## Возможности

- Анализ BPM и моментов битов с помощью `librosa`.
- Автоматическая нарезка исходных видео на короткие фрагменты, общий
  пул, случайная выборка.
- Сборка итогового видео так, что каждый сегмент начинается ровно на
  бите. Длина каждого сегмента подгоняется к интервалу между битами.
- Три режима подгонки длины: `loop` (зацикливание), `speed` (ускорение/
  замедление), `trim` (обрезка только с начала).
- Унификация разрешения и FPS, центрирование с чёрными полями при
  разном соотношении сторон.
- Замена или микширование оригинального звука видео с музыкой.
- Прогресс-бар, журнал, фоновое выполнение в потоке, кнопка «Отмена».
- Fallback-режим: если ритм определить не удалось, равномерная сетка.

## Скриншот

Тёмная тема, серо-чёрные тона, минимальные акценты.

## Установка

Требуется **Python 3.8+** и **ffmpeg** (как внешняя утилита, либо через
`imageio-ffmpeg`, который ставится автоматически вместе с moviepy).

### Linux / macOS

```bash
git clone https://github.com/loco842/laba1.git
cd laba1
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

Установите `ffmpeg`, если он ещё не установлен:

- Ubuntu/Debian: `sudo apt install -y ffmpeg`
- macOS (Homebrew): `brew install ffmpeg`

### Windows

```powershell
git clone https://github.com/loco842/laba1.git
cd laba1
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt
```

`ffmpeg` уже включён через зависимость `imageio-ffmpeg`, отдельно
устанавливать не обязательно.

## Запуск

```bash
python run.py
```

или эквивалентно:

```bash
python -m beat_video_cutter
```

После запуска откроется окно приложения. Шаги:

1. Кнопкой **Обзор** выберите папку с исходными видео.
2. Выберите аудиофайл (саундтрек).
3. Укажите путь к выходному файлу (по умолчанию `output.mp4`).
4. При необходимости поправьте параметры монтажа.
5. Нажмите **Старт** и дождитесь окончания работы.

## Поддерживаемые форматы

- Видео: `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.m4v`, `.flv`, `.wmv`
- Аудио: `.wav`, `.mp3`, `.aac`, `.flac`, `.ogg`, `.m4a`

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `clip_duration` | `2.0` сек | Длина нарезаемых фрагментов-заготовок |
| `beat_divider` | `1` | Шаг выбора битов (1 = каждый бит, 2 = каждый второй) |
| `min_clip_remains` | `0.5` сек | Минимальная длительность остатка, который добавляется в пул |
| `output_width` / `output_height` | автоматически | Целевое разрешение (если пусто — максимум из исходных) |
| `output_fps` | `30` | Целевая частота кадров |
| `keep_original_audio` | выкл | Микшировать оригинальный звук видео с музыкой |
| `audio_mix_ratio` | `0.2` | Доля музыки при микшировании (0..1) |
| `codec_video` | `libx264` | Видеокодек ffmpeg |
| `codec_audio` | `aac` | Аудиокодек ffmpeg |
| `preset` | `medium` | Preset libx264 |
| `bitrate` | авто | Битрейт, например `4M` |
| `length_fit_mode` | `loop` | `loop` / `speed` / `trim` — как подгонять длину фрагмента под интервал |
| `seed` | — | Seed для воспроизводимой случайной выборки |

## Алгоритм

1. **Анализ аудио.** `librosa.beat.beat_track` даёт темп и кадры
   битов, переводим в секунды. Если темп не определился — fallback на
   равномерные интервалы.
2. **Пул фрагментов.** Каждое видео в папке нарезается на отрезки
   длиной `clip_duration`. Остаток короче `min_clip_remains`
   отбрасывается.
3. **Интервалы.** `[0, beat₁, beat₂, …, beatₙ, audio_duration]` →
   список пар `(start, end)`.
4. **Сборка.** Для каждого интервала случайно берётся фрагмент из
   пула. Если он длиннее интервала — обрезается; короче — зацикливается
   (или ускоряется в режиме `speed`). Сегмент масштабируется и
   центрируется под целевое разрешение, FPS унифицируется.
5. **Экспорт.** Все сегменты конкатенируются, поверх накладывается
   музыкальная дорожка, видео кодируется в MP4 (`libx264` + `aac`).
